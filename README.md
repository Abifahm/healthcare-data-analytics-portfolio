Project 1: Problem Solving using Pareto Analysis
Case Study: Valley view Hospital
Problem statement: Valley view Hospital has experienced an increase in prolonged patient admissions, affecting bed availability and overall patient flow. 
Objective- To identify the main factors contributing to extended hospital stays, measure their impact on excess bed days, and recommend improvements to patient flow without compromising patient safety.
Method= Pareto Analysis- I applied the Pareto principle to prioritise the factors contributing most to excess bed days. This involves ranking the contributing factors from highest to lowest impact and calculating their cummulative percentage to identify the areas that should receive the most attention.
Key Findings- The analysis aim to halving the top 3 drivers frees about 2,400 bed-days a month and brings average LOS from 6.1 toward 5.3 days within 6 months. fewer ED patients waiting for a bed and fewer postponed elective surgeries, because beds become available sooner,  Lower cost per admission, and less need for overflow beds, agency staff and overtime. fewer complications linked to long stays, higher satisfaction, and no rise in readmissions, which confirms patients are being discharged safely.
Project 2: Excel Analytics using cell referencing
Project Overview: This project demonstrates my understanding of cell referencing in Microsoft Excel through practical exercises and case studies.
Objective- To learn how to use different cell referencing techniques to perform calculations accurately and efficiently.
Method- Relative Referencing (A1)- Allows a cell reference to change  automatically when formula is copied to another cell. Absolute Referencing ($A$1)- keeps both the column and row fixed when copying a formula. Mixed Refrencing ($A1 or A$1) Keeps either the column or the row fixed while allowing the other to change.
Activities completed- Practised realtive and Absolute cell referencing. I applied formulas to different case studies, Copied formulas across cells to observe how references changed, compared the results to understand when each techniques is useful.
Key Learning- I learned how to use cell refrencing to make calculations more consistent, reduce repetitive work and improve accuracy when working with spreadsheets.
